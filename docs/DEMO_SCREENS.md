# Demo screens: real onboarding + where we charge

Add these so the demo shows the FULL journey: onboarding both sides, and the exact moment/screen where the platform charges. Do not break existing flow. These slot in.

## Overview of the full demo journey

Landing (two doors) → 
  SPONSOR path: sign up → quiz → matching (loading) → matches → profile detail → connect → deal room (WHERE WE CHARGE)
  CLUB path: sign up → build profile → live preview (discoverable)

## 1. Sponsor onboarding (new — before the quiz)

A short sign-up so it feels like a real account, not an anonymous quiz.
- Screen: "Create your sponsor account" — company name, email, country. One clean screen.
- On submit → go into the quiz (which already exists).
- Keep it 3 fields max. This is onboarding flavor, not a real auth system.
- Show a tiny "membership" note: "Free to browse and match. Sponsor membership unlocks contacting clubs and closing deals." This plants the paywall early (see charging below).

## 2. Club/athlete onboarding (make the second door real)

- Screen: "Create your club/athlete profile" — name, type (club/athlete), sport, country/city.
- Then: profile builder — audience size, socials (optional), what you offer sponsors (multi-select), typical deal range.
- End: "You're live" preview showing how sponsors see them, with the trust badge (self-reported / corroborated).
- Free, always. Say so on screen: "Free to list. You only ever share value when a deal closes."

## 3. WHERE WE CHARGE — make this a clear, explicit screen

This is the key addition. The demo must SHOW the charge, not imply it. Two charge points:

### Charge point A — Sponsor membership (the gate)
When a sponsor tries to CONTACT/CONNECT with a matched club, show a membership screen:
- "Contact clubs and close deals with a Sponsor membership."
- Show the plan clearly: e.g. "€X / month — unlimited matching, contact any club, deal support, reporting."
- Free tier: browse + see matches. Paid: contact + close.
- A clear "Start membership" button → then proceeds to connect.
- This is recurring revenue and it's VISIBLE. The judge sees exactly where money enters.

### Charge point B — Commission at deal close (the deal room)
After connect, the deal room screen (status tracker: connected → negotiating → agreed → live) shows the commission explicitly:
- Agreed deal value field (prefill an example, e.g. €8,000).
- Commission line: "Platform commission (10% on deals under €10k): €800."
- "You pay commission only when a deal closes. Free to negotiate."
- A clean breakdown box: Deal value / Commission / What the club receives.

So the demo shows BOTH revenue lines on real screens:
- Recurring: sponsor membership gate (charge point A).
- Transactional: commission in the deal room (charge point B).

## 4. A tiny "pricing" / how-we-make-money screen (optional but strong)

One clean screen (linkable from a header "Pricing" or shown in the pitch) that lays out the model at a glance:
- Clubs & athletes: Free. Always.
- Sponsors: €X/month membership to contact and close.
- Plus: small commission on closed deals (2% large / 10% small).
- "We only grow when sport gets funded."
Having this as an actual screen means when a judge asks "how do you make money," you click to it instead of hand-waving.

## Rules
- Keep the existing quiz, matching, and detail screens intact.
- Onboarding = flavor, 3 fields max, no real auth.
- The charge points must be EXPLICIT screens the demo can land on.
- Copy stays honest: clubs free, sponsors pay membership + commission on close.
- Same visual style throughout.

## Priority
1. Charge point A (membership gate on contact) — most important, shows recurring revenue.
2. Charge point B (commission in deal room) — shows transactional revenue.
3. Sponsor + club onboarding screens — makes it feel real.
4. Pricing screen — nice for Q&A.
